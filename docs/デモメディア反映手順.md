# デモメディアへのデータ反映と外部媒体申請の手順(T-19)

T-19(デモメディアの立ち上げ)のうち、**実際に本番相当のライブ環境(`https://jobcone.m-cording.com`)へ
触れる作業と、外部サービスへの申請作業**をまとめた手順書。

この2つは Claude(このリポジトリで作業しているAI)からは実行できない。SSH の秘密鍵は
リポジトリに置かれておらず(置くべきでもない)、外部サイトへのログイン・申請は
実在の事業者としての判断・登録が必要なため。**人が実行することを前提にした手順書として書く。**

ローカルで確認済みの内容(架空データのシーダー・エンドツーエンドの動作確認・
フィード出力の確認)は [TASKS.md](../TASKS.md) T-19 の「使ってみて気づいた問題」節を参照。

## 1. デモデータをデモメディアへ反映する

前提として [デプロイ手順.md](デプロイ手順.md) の通常デプロイが完了していること
(コード自体は最新)。ここではその後に行う、架空データの投入だけを扱う。

```bash
ssh xs413120@sv16436.xserver.jp -p 10022
cd ~/jobcone_app   # 環境台帳.md 記載のディレクトリ名

# SSH の php は既定バージョンが異なるため php8.4 を明示する(デプロイ手順.md 2章と同じ理由)
php8.4 artisan db:seed --class=DemoMediaSeeder
```

**注意**

- `DemoMediaSeeder` は架空の介護事業所 6 社・求人 31 件超を投入する
  ([database/seeders/DemoMediaSeeder.php](../database/seeders/DemoMediaSeeder.php))
- `firstOrCreate` を使っているため、**再実行しても重複しない**(同名の企業・事業所があれば
  スキップされ、求人はまだ求人が無い事業所にだけ追加される)
- 掲載企業ログインのパスワードは全社共通で `demo-pass-2026`(シーダー内に定義。
  営業デモ専用の値であり、実在の顧客環境では絶対に使わないこと)
- **絶対に `DatabaseSeeder` の呼び出し一覧に `DemoMediaSeeder` を追加しないこと。**
  `php artisan db:seed`(引数無し)は全環境の通常運用で実行されるコマンドであり、
  混ざると顧客環境に架空の企業・求人が入ってしまう(CLAUDE.md 3.1)

### 1.1 反映後の確認

```bash
php8.4 artisan tinker --execute="
echo \App\Models\Company::count() . ' 社' . PHP_EOL;
echo \App\Models\JobPosting::where('status','published')->count() . ' 件公開' . PHP_EOL;
"

# アグリゲーションフィードを再生成する
php8.4 artisan feeds:generate
```

- ブラウザで `https://jobcone.m-cording.com/` を開き、求人件数が増えていることを確認する
- `https://jobcone.m-cording.com/feed/indeed.xml` 等を開き、求人が出力されていることを確認する
- 掲載企業ログイン(`https://jobcone.m-cording.com/company/login`)で
  `demo-sakura@jobcone.example.com` などシーダー内の `login_email` を使ってログインできることを確認する

## 3. アグリゲーション媒体への申請

対象は Indeed・求人ボックス・スタンバイの3媒体([SPEC.md 10.1](../SPEC.md#101-対応する媒体))。

**申請方法は各媒体の公式サイト上の手続きであり、随時変わる。** このドキュメントには
具体的な申請ページの URL は書かない(SPEC.md 10.3 の通り、実施時点の公式情報を
必ず確認すること)。各媒体の「求人サイト運営者向け」「フィード掲載申請」
といった名称のページを、その時点の検索で探して申請すること。

申請時にこちらから提示する技術情報は以下の通り(すでに動作確認済み)。

| 項目 | 値 |
|---|---|
| メディア名 | JobCone(デモメディア。実運用は顧客ごとのメディア名に読み替える) |
| メディアURL | `https://jobcone.m-cording.com` |
| Indeed 向けフィード | `https://jobcone.m-cording.com/feed/indeed.xml` |
| 求人ボックス向けフィード | `https://jobcone.m-cording.com/feed/kyujinbox.xml` |
| スタンバイ向けフィード | `https://jobcone.m-cording.com/feed/stanby.xml` |
| フィード形式 | XML(媒体ごとのフォーマット。`app/Services/Feed/` 参照) |
| 更新頻度 | 日次(`routes/console.php` の `feeds:generate` スケジュール) |

**申請前に、上記フィード URL が実際に求人を含んだ状態で 200 を返すことを確認してから
申請すること**(1章の反映作業が先に必要)。審査に数日〜数週間かかる媒体もあるため、
商談の日程から逆算して早めに申請する。

申請が完了したら、[環境台帳.md](環境台帳.md) の「デモメディア(JobCone)」の
個別メモに申請日・審査状況を追記しておく。
