## 顧客ごとの個別メモ

環境ごとに特記事項があればここに追記する(テーマのカスタマイズ内容、
顧客固有の運用ルール、連絡先など)。**コードを分岐させる代わりに、
差異はここへの記録と `site_settings` の設定値で表現する(CLAUDE.md 3.1)。**

### デモメディア(JobCone) — 実機確認で判明した Xserver 固有事項

- `symlink()` は使える(2章の代替手順は不要だった)
- SSH のユーザー名はメールアドレスではなく **サーバーID**(`xs413120`)。ホスト名はサーバー番号 + `.xserver.jp`、ポートは `10022`
- SSH は公開鍵認証のみ。パスワード認証は不可
- **SSH の `php` / `composer` は CLI 既定のバージョン(このサーバーでは PHP 8.0)を指し、ドメインの「PHP Ver.切替」は Web 実行にしか反映されない。** `php8.4` を明示するか `PHP_BIN=php8.4` で上書きする(→ [デプロイ手順.md](デプロイ手順.md) 2章、[新規環境の構築手順.md](新規環境の構築手順.md))
- MySQL の接続ホストは `localhost` で到達できた
- WebP 対応(`imagewebp`)は利用可能
