# 環境台帳(T-18)

顧客ごとに立ち上げた環境の一覧。**新規環境を構築したら必ずここに追記し、
デプロイのたびに「現在のバージョン」「最終デプロイ日」を更新する。**

この記載が漏れると、一斉デプロイ([デプロイ手順.md](デプロイ手順.md))のときに
対象環境が漏れる・存在しない環境を触ろうとする、といった事故につながる。

---

## 環境一覧

| 顧客名 | ドメイン | サーバ(Xserverアカウント) | 契約プラン | 導入日 | 現在のバージョン | 最終デプロイ日 | 備考 |
|---|---|---|---|---|---|---|---|
| (まだ環境なし) | - | - | - | - | - | - | T-19 でデモメディアを最初の環境として構築する予定 |

- **現在のバージョン**: `git rev-parse --short HEAD` の値、またはリリースタグ名
- **契約プラン**: ベーシック / スタンダード / プレミアム(SPEC.md 6.2)

## 顧客ごとの個別メモ

環境ごとに特記事項があればここに追記する(テーマのカスタマイズ内容、
顧客固有の運用ルール、連絡先など)。**コードを分岐させる代わりに、
差異はここへの記録と `site_settings` の設定値で表現する(CLAUDE.md 3.1)。**
