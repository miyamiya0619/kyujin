## 1. 一言で

**介護・医療・福祉に特化した求人メディアを、自社ブランドで、最短で立ち上げる。**

ゼロから開発すれば数百万円・半年以上かかる求人メディアを、
初期費用 50〜150万円・月額 5〜10万円・導入支援付きで提供する。

同カテゴリの製品として [jobMAKER(株式会社プロシーズ)](https://jobmaker.jp/) があり、
700サイト以上の構築実績を持つ。本製品はこの領域に **介護・医療・福祉特化のマスタと
アグリゲーション連携** を組み込んで参入する。

---

## 2. こんな課題を解決する

| 課題を持つ相手 | 解決すること |
|---|---|
| 介護業界団体・地域メディア運営者 | 自前の求人サイトを持てば、会員事業所の掲載料という新しい収益源になる |
| 人材会社 | 既存の紹介事業に加えて、掲載型のメディア事業を立ち上げられる |
| 個々の介護事業所 | Indeed・求人ボックス・スタンバイに同時配信されるため、1回の入稿で複数媒体に露出できる |

## 4. 機能一覧

### 4.1 公開メディアサイト(求職者向け)

| 画面 | 内容 |
|---|---|
| トップページ | 注目求人・新着求人・条件から探す・特集枠 |
| 求人検索・一覧 | 都道府県・市区町村・職種・資格・施設形態・雇用形態・夜勤有無・こだわり条件で絞り込み |
| 求人詳細 | 仕事内容・給与・勤務時間・待遇・必要資格・事業所情報・応募ボタン(構造化データ対応) |
| 事業所・企業紹介 | 掲載企業と事業所の紹介ページ |
| 会員登録・マイページ | 求職者は登録しておけば応募のたびに入力し直す必要がない |

検索エンジン対策(サーバサイドレンダリング・構造化データ・サイトマップ・OGP)を標準で備える。
求人メディアにとって集客の生命線となる部分。

### 4.2 掲載企業向け管理画面

| 機能 | 内容 |
|---|---|
| ダッシュボード | 掲載中の求人数・未対応の応募件数・掲載プランの残枠が一目で分かる |
| 事業所管理 | 事業所の登録・編集(名称・住所・施設形態・写真) |
| 求人管理(セルフ入稿) | 求人の作成・編集・複製・審査への提出 |
| 応募者管理 | 応募一覧、選考ステータス変更、社内メモ、応募時点の履歴書閲覧 |
| 企業情報 | 企業紹介文・ロゴの管理 |

### 4.3 運営者向け管理画面

| 機能 | 内容 |
|---|---|
| 審査待ち一覧 | 掲載企業が提出した求人を審査・差戻し・公開(運営者の日常業務の中心) |
| 掲載企業管理 | 企業の登録、担当者アカウント発行、掲載プランの割当 |
| 掲載プラン管理 | 掲載可能件数・掲載期間・上位表示の有無・表示価格を自由に定義 |
| 求人の代行入稿 | 掲載企業に代わって運営者が入力(立ち上げ期に有効) |
| サイト設定 | メディア名・ロゴ・テーマ・連絡先・規約・審査ON/OFFの切り替え |
| マスタ管理 | 資格・施設形態・職種などマスタの有効/無効と並び順 |
| 応募の横断確認 | 全掲載企業の応募状況を運営者側から確認 |
| データ返還・完全削除 | 解約時に全データをエクスポートし、完全に削除できる |

### 4.4 求職者マイページ

プロフィール・保有資格・職務経歴の登録、応募履歴と選考ステータスの確認、退会。

### 4.5 アグリゲーション連携(★主要な強み)

Indeed・求人ボックス・スタンバイ向けに、公開中の求人を自動でフィード配信する。
1回の入稿で複数の求人媒体に露出できるため、掲載企業にとっての掲載価値が上がる。

## 6. 初期費用に含まれる導入支援

| 工程 | 内容 |
|---|---|
| 1. ヒアリング | メディアのコンセプト、対象エリア、掲載プランの設計、公開スケジュール |
| 2. 環境構築 | サーバ契約、ドメイン設定、SSL、システム設置 |
| 3. 初期設定 | サイト設定、マスタの有効/無効と並び順、掲載プランの定義、規約文面 |
| 4. デザイン | 標準テーマの適用と色・ロゴ調整(個別制作は別料金) |
| 5. データ移行 | 既存の求人・企業データの投入(CSV) |
| 6. アグリゲーション申請 | Indeed・求人ボックス・スタンバイへのフィード登録申請の代行 |
| 7. 操作研修 | 運営者向け(審査・企業管理)、掲載企業向けのマニュアル提供 |
| 8. 公開後フォロー | 初月の運用サポート |

## 7. よくある質問(想定)

**Q. 他社の求人サイト構築サービスと何が違う?**
介護・医療・福祉に特化したマスタ(資格・施設形態・職種・こだわり条件)を最初から
備えている点、アグリゲーション連携が標準搭載である点が違い。

**Q. 掲載企業ごとにデザインを変えられる?**
色・ロゴの調整は初期費用の範囲内。個別デザイン制作は別料金(プレミアムプランのみ)。

**Q. 解約したらデータはどうなる?**
全データをエクスポートした上で完全に削除できる仕組みを標準で備えている。
